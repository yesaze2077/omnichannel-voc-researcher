# Contributing

1. Open an issue describing the channel-neutral research problem and expected behavior.
2. Use synthetic fixtures. Never attach real comments, transcripts, customer data, API keys, cookies, author identifiers, private paths, or commercial study material.
3. Contributions must remain suitable for noncommercial learning and must not add CAPTCHA bypass, identity/proxy rotation, fingerprint spoofing, private endpoint discovery, private-content access, or policy-evasion behavior.
4. Keep `SKILL.md` focused and put detailed source guidance in `references/`.
5. Run `python3 tests/run_tests.py` and `python3 -m py_compile scripts/*.py tests/run_tests.py` before opening a pull request.

By contributing, you agree that your contribution will be distributed under the repository license and notices.
