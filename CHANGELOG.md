# Changelog

## 1.3.0 - 2026-11-03

- Added frozen scope and explicit user-referenced revision history for required channels, roles/members, record/parent floors, and quality thresholds.
- Added source-local login/connection-verification checkpoints and user-assisted resumption requiring both actual user completion and visible readable-body evidence; real denial, 403/429, and rate limits still stop the restricted route.
- Continued independent executable collection/preparation while one source, taxonomy calibration, or audit waits.
- Kept unknown increments and unsuccessful/unattempted rounds out of saturation; unfinished required channels must satisfy their own measured expansion rules.
- Added one input-hash-bound delivery-acceptance path for built-in and custom reports, mandatory receipts/HTML markers, and progress snapshots that cannot imply task completion.
- Allowed smaller justified teaching/pilot targets declared before collection while preserving promised channels; removed automatic escalation to a 350-record minimum.
- Preserved rating-recovery mode, evidence-class separation, privacy, source traceability, and visual QA requirements.
- Added behavioral evaluations for assisted verification, checkpoint resume, scope drift, local waits, unknown yield, custom report bypass, and stale receipts.

## 1.2.0 - 2026-08-19

- Added a `rating-recovery` mode with baseline-freeze, direct-model, recent-window, low-star, and rating-driver gates.
- Added a driver tree separating product defects, setup/workflow friction, expectation mismatch, support recovery, and insufficient evidence.
- Added app stores as a planned completion family when an app is part of the product workflow.
- Added rating-recovery search dimensions for low-star risk, expectation mismatch, and successful service recovery.
- Made Report IR and visual-report QA explicitly cover rating baseline provenance, action lanes, hold period, and guardrails.
- Added deterministic regression coverage and a realistic rating-recovery evaluation prompt.

## 1.1.2 - 2026-08-18

- Added regression coverage for safe country, language, variant, and variant-scope passthrough fields.
- Kept the passthrough contract whitelist-only so credentials, cookies, tokens, raw author names, and arbitrary bridge fields remain excluded.
- Made report traceability validation accept preserved bridge IDs and multilingual multi-label disclosures without truncating IDs to a guessed hash shape.

## 1.1.1 - 2026-08-18

- Added explicit Reddit authorization labels and approved-scope recording without retaining credentials or account identifiers.
- Added Old Reddit preferred-entrypoint and normal Reddit one-step fallback fields to search matrices.
- Added `configure_reddit_access.py` so existing matrices can be updated without changing query IDs.
- Added deterministic tests for authorized Old Reddit matrix generation and reconfiguration.
- Preserved safe collection-context fields, stable incoming source IDs, and original collection timestamps during normalization.

## 1.1.0 - 2026-08-18

- Added channel `record_floor`, `record_goal`, and `record_cap` semantics plus documented reallocation to core open sources.
- Added deterministic pilot, formal, gap-driven, and supplemental search-matrix generation with balanced query dimensions and a negative-query cap.
- Added per-query/per-round yield measurement and enforced evidence for the two-successive-below-5% saturation rule.
- Added a collection-state resolver that prevents `needs_append` and `waiting_for_user_login` studies from being presented as final.
- Added explicit normal-login pause behavior without credential handling; CAPTCHA, checkpoints, 403, 429, and access limits still stop the route.
- Updated quality gates to read standalone or nested sample plans and distinguish source floors, goals, and caps.

## 1.0.0 - 2026-08-12

- Added decision- and depth-aware post-clean sample planning.
- Made YouTube, searchable public forums, and Old Reddit the core sources for deep public-web studies.
- Added YouTube API-first search, metadata, top-level comment, and reply collection guidance.
- Separated raw YouTube candidate targets, retained comments, relevant videos, and transcript-video denominators.
- Added small interpretability floors and stop rules for X, TikTok, Facebook, and Instagram.
- Added record-count and independent-parent quality gates.
- Added noncommercial learning-use licensing, platform-policy boundaries, and third-party-rights notices.
