# Security and Privacy Boundary

This repository is for noncommercial learning and technical exchange only. Its software license does not grant permission to access or reuse third-party platform data. Read `NOTICE.md` before any live study.

This skill performs local normalization, cleaning, coding validation, statistics, and report generation. It does not bundle credentials or bypass logic.

- Keep API keys, cookies, session data, passwords, and browser profiles outside study files.
- Use user-authorized read-only access. Confirm before any external write or account change.
- Stop browser collection on CAPTCHA, checkpoint, re-authentication, rate limit, or access restriction.
- Do not use proxy rotation, identity rotation, fingerprint spoofing, or private endpoint discovery.
- Hash author identifiers before normalization and omit hashes from reports.
- Keep raw data private. Publish reusable code, synthetic fixtures, and aggregate reports only.
- Review platform terms, privacy obligations, retention, and business-use rights for every live study.
- Do not use the project for commercial data services, resale, surveillance, profiling, or recurring collection without every required software, platform, content, data, and privacy authorization.
